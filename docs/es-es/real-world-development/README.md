Explora GitHub Copilot a lo largo del ciclo de vida del desarrollo de software con escenarios realistas, una aplicación completa y un backlog compartido. Trabajarás de forma iterativa para planificar cambios, crear código, probar su comportamiento, revisar solicitudes de incorporación de cambios y gestionar el trabajo con agentes.

## Escenario

Eres un nuevo desarrollador de Tailspin Toys, una empresa ficticia que ofrece financiación colectiva para juegos de mesa con temática de programación. El backlog de tu equipo ya está registrado en incidencias de GitHub para que puedas empezar a trabajar. Incluye funcionalidades como el filtrado y la paginación, además de mejoras de calidad relacionadas con la accesibilidad y los estándares de código.

## Elige tu entorno

GitHub Copilot te acompaña dondequiera que trabajes. Elige el entorno que mejor se adapte a tu forma de desarrollar. Cada taller tiene su propia configuración y utiliza el escenario compartido de Tailspin Toys.

### [GitHub Copilot CLI][cli]

Usa el asistente con agentes en el terminal. Trabaja con los modos Plan y Autopilot, instrucciones, habilidades, agentes personalizados, Playwright MCP, Agent Merge y prácticos comandos de barra.

### [Aplicación GitHub Copilot][app]

Ejecuta sesiones de agente en paralelo, cambia entre modos de sesión, colabora en lienzos y gestiona incidencias y solicitudes de incorporación de cambios de GitHub en la aplicación de escritorio.

### [Agente de GitHub Copilot en la nube][cloud]

Asigna incidencias de GitHub a un agente asíncrono, guía su trabajo, supervisa su progreso y revisa las solicitudes de incorporación de cambios que abre.

### [Visual Studio Code][vscode]

Usa GitHub Copilot en Visual Studio Code y GitHub Codespaces. Trabaja con el modo agente de Copilot Chat, servidores MCP y agentes personalizados sin salir del editor.
